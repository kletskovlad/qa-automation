Лабораторна робота №2

Тема: Модульне тестування бізнес-логіки засобами Vitest. Матчери, параметризовані тести, покриття коду.

Індивідуальний варіант: №5 — splitPayment(total, parts).
Реалізовані функції

    calcSubtotal() — обчислення загальної вартості товарів.
    calcDiscountRate() — розрахунок знижки залежно від рівня клієнта.
    calcShipping() — визначення вартості доставки.
    calcOrderTotal() — розрахунок остаточної суми замовлення.
    splitPayment() — розбиття суми на декілька платежів із точністю до копійок.

Проведене тестування

    Створено 43 тести для бізнес-логіки замовлень.
    Використано параметризовані тести it.each().
    Перевірено межові значення та некоректні вхідні дані.
    Застосовано матчери toBe(), toEqual(), toBeCloseTo() та toThrow().
    Проведено експеримент із тестом без перевірки результату.
