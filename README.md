## Лабораторна робота №4

**Тема:** Тестові дублери, ізоляція залежностей, підміна часу та HTTP-запитів засобами MSW.

**Індивідуальний варіант:** №5 — обмежувач частоти звернень до зовнішнього API: не більше 3 викликів за 10 секунд.

### Реалізовані функції

- `OrderService` — обробка замовлень із впровадженням залежностей через конструктор.
- `InMemoryOrderRepository` — підробка сховища замовлень.
- `withRetry()` — повторне виконання операцій після помилок.
- `HttpRateProvider` — отримання курсу валют через HTTP.
- `ApiRateLimiter` — обмеження кількості API-запитів у ковзному часовому вікні.
- `InMemoryRequestStore` — збереження часових позначок запитів у пам'яті.
- `HttpApiClient` — HTTP-клієнт із перевіркою статусу та формату відповіді.

### Проведене тестування

- Використано заглушки (Stub), шпигуни (Spy) та підробки (Fake).
- Реалізовано впровадження залежностей через конструктори та інтерфейси.
- Перевірено результат роботи й взаємодію із залежностями.
- Виконано експеримент «Стан проти взаємодії».
- Використано `vi.useFakeTimers()`, `vi.setSystemTime()` та `vi.advanceTimersByTimeAsync()`.
- Перевірено повторні спроби виконання операцій.
- Налаштовано MSW із `onUnhandledRequest: 'error'`.
- Перевірено успішні HTTP-відповіді, статус 503, мережеві помилки та некоректні JSON-дані.
- Перевірено сценарії відмов зовнішнього API та сховища.

### Індивідуальний варіант №5

- Перші три API-запити протягом 10 секунд дозволяються.
- Четвертий запит у межах часового вікна блокується з помилкою `RATE_LIMIT_EXCEEDED`.
- Через рівно 10 секунд звільняється місце для нового запиту.
- Реалізовано ковзне часове вікно.
- Час контролюється без реального очікування.
- Перевірено, що заблокований запит не надсилається до зовнішнього API.
