## Мета роботи

Розгорнути середовище автоматизації тестування на базі Node.js і TypeScript, налаштувати Vitest, ESLint і Prettier, розробити та протестувати програмний модуль.

## Індивідуальне завдання

Реалізувати функцію перевірки високосного року з відхиленням від'ємних і нецілих значень.

## Встановлення

Для встановлення залежностей виконайте:

```bash
npm install
```

## Запуск тестів

```bash
npm test
```

## Режим спостереження

```bash
npm run test:watch
```

## Перевірка покриття

```bash
npm run coverage
```

## Перевірка коду

```bash
npm run lint
```

## Форматування коду

```bash
npm run format
```
